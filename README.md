# J. Inspired Fashion Storefront

A fully responsive premium clothing storefront inspired by elegant J. style, designed with emerald green, black, white, and gold accents.

## Features
- Luxury hero banner and home page
- Men, Women, Kids, and Accessories categories
- Search and category filtering
- Product cards with original price and 50% discount
- Product details modal with gallery
- Add to cart, quantity controls, wishlist
- Cart summary with subtotal, discount, final total
- Checkout form with customer details
- WhatsApp order button
- Contact section with WhatsApp, phone, and social links
- Responsive layout for mobile, tablet, and desktop

## Pricing note
This demo uses sample pricing because official J. product pricing was not provided. Every product displays a 50% discount automatically from the original price shown.
